## Glossaire (terme : définition)

- **BO** : Back-office (interface d'administration / gestion).
- **FO** : Front-office (interface vue par l'utilisateur final).
- **App Mobile** : application mobile (Android / iOS).
- **App TV** : application TV (Android TV, etc.).
- **Web** : le site / l'application web (par opposition aux apps).
- **Plateforme / client** : l'instance d'un client donné (le « qui » est concerné).
